# 素材の棚卸し — 何が描けて、何が描けないか

食料の獲得手段を増やそうとするたびに「その絵はあるのか」から始めることになる。ここで一度、
実際に描画して確かめた結果を残す。**推測ではなく、8倍から20倍に拡大して目で見た内容だけを
書く。** 過去に3度、タイルの中身を思い込みで書いて外している。

## 手持ちのパック

Kenney の CC0 パックが3つ、いずれも 16×16、132タイル。同じ作者・同じ系列なので画風は揃う。

| パック | タイル数 | 使用中 | 用途 |
| --- | --- | --- | --- |
| tiny-town | 132 | 25 | 地形・建物・資源 |
| tiny-dungeon | 132 | 9 | 住民の顔、墓標 |
| tiny-farm | 132 | 2 | 農夫の顔。畑と作物は農耕の Task 8 で入る |

396枚のうち使っているのは36枚である。まだ9割が手つかずで、足りないのは素材ではなく
使い道のほうである。

## 住民の顔

現在10枚。tiny-dungeon の 0084 / 0085 / 0086 / 0088 / 0098 / 0099 / 0100 / 0112 に、tiny-farm の
農夫2枚（0108 = 青いオーバーオール、0109 = 麦わら帽子）を加えた（`d5bfdf3`）。パックは違うが
同じ作者・同じ系列・同じ 16×16 なので、並べても継ぎ目が出ない。

`agentSpritePath` は住民IDのハッシュで顔を選ぶ。割り当ては順番ではないので、**10人目まで
重複しないわけではなく、それよりずっと早く重なる**。`MAX_POPULATION` が10である以上、
通常の人口でも同じ顔は並ぶ。枚数を増やしても重複が始まる人数が動くのではなく、重なる確率が
下がるだけである。

`sprites.test.ts` は住民ID 400件をサンプルして顔の集合が全要素を覆うことを確かめているので、
追加した2枚に到達できることは自動で検証される。

### 使えない顔

tiny-dungeon 0108（緑のスライム）、0109（単眼）、0110（**カニ**）、0111（赤い目のフード姿）、
0120（コウモリ）、0121（幽霊）、0122（クモ）、0123・0124（ヘビ）は住民に使えない。
以前これらを肌色の走査で数えたとき 0110 と 0111 を人間と誤判定した。走査ではなく描画で
確かめること。

**番号はパックをまたいで意味が変わる。** tiny-farm の 0108 / 0109 は農夫だが、tiny-dungeon の
0108 / 0109 は緑のスライムと単眼である。番号だけで指さず、必ずパック名とセットで書くこと。

## 獲得手段ごとの素材の有無

| 手段 | 素材 | 判定 |
| --- | --- | --- |
| 農耕 | tiny-farm 0000/0001（耕地）、0064→0065→0066（芽→株→実り）、0068（束） | **ある** |
| 採集（キノコ） | tiny-farm 0079 — 傘と柄のあるキノコ、20倍で確認 | **ある** |
| 採集（木の実） | tiny-farm 0078 — 赤い実のなる緑の低木 | **ある** |
| 採集（山菜） | tiny-farm 0080 — 緑の葉物、0081 — 土から出た芽 | **ある** |
| 磯採り | tiny-dungeon 0110 — 赤いカニ。水辺のタイルが必要 | **ある** |
| 牧畜 | tiny-farm 0120（羊）、0121（牛）、0122（鶏）、0123（乳桶らしきもの） | **ある** |
| 狩猟 | 鹿・猪・兎にあたるタイルが3パックのどこにもない | **ない** |
| 漁労 | 魚のタイルがない | **ない** |

狩猟と漁労だけが素材の壁で止まっている。やるなら罠や籱——仕掛けて後日回収する形——にすれば
獲物の絵なしで成立するが、それは獲得手段というより別の仕組みである。

## 次に足すなら

**この表は「何が描けるか」しか答えていない。何を足すべきかは答えていない。**

農耕を入れたあと、収穫前の谷がどれだけ深く、どれだけ続くかを実測する。その数字を見るまで
採集と牧畜のどちらを先にするかは決めない。ここで順番を決めてしまうと、測定が決めるはずの
ことを素材の都合で先に決めることになる。

分かっているのは、両者が谷に対して逆向きに働くらしいということだけである。細く一定の流れは
谷を埋め、季節に紐づく供給は谷の形を変える。どちらが要るかは谷を見てから決める。
